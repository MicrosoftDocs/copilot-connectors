# Deploy the Coda Enterprise Microsoft 365 Copilot connector

The Coda Enterprise Microsoft 365 Copilot connector allows your organization to index documents and pages from your Coda Enterprise environment. This article describes the steps to deploy and customize the Coda Enterprise connector.

## Prerequisites

Before you deploy the Coda Enterprise connector, make sure you meet the following prerequisites:

- You must be a AI administrator for your organization’s Microsoft 365 tenant.
- You must have a Coda org administrator account to obtain the API token for indexing content.
- The connector supports only the Coda Enterprise edition. Coda Free, Pro, and Team editions aren't supported due to API restrictions.
- You must generate a Coda Enterprise API token from **Account settings** > **API settings** in the Coda Org Admin account.
- Make sure that you have the **Coda Enterprise organization ID**, which follows a structure similar to `org-AbCDeFGHIj`.

## Deploy the connector

To add the Coda Enterprise connector for your organization:

1. In the Microsoft 365 admin center, in the left pane, choose **Copilot** > **Connectors**.
1. Choose the **Gallery** tab.
1. From the list of available connectors, choose **Coda Enterprise**.

### Set display name

The display name identifies references in Copilot responses to help users recognize the associated file or item. You can accept the default **Coda Enterprise** display name or customize it.

For more information about connector display names and descriptions, see [Enhance Copilot discovery of connector content](/microsoft-365-copilot/connectors/enhancing-microsoft-copilot-discovery-with-graph-connector-content).

### Set instance URL

Provide the Coda Enterprise organization ID. The format typically resembles:

`org-AbCDeFGHIj`

You can find the organization ID in the Coda admin settings page URL, for example:

`https://coda.io/organizations/org-AbCDeFGHIj/about`

### Choose authentication type

Coda Enterprise supports **API token authentication**. Use a token generated by a Coda Org Admin. The following table lists the default values for token creation.

| Field | Default value |
|-------|---------------|
| Type of restriction | Doc or table |
| Type of access | Read and write |
| Doc or table to grant access to | Not required (leave empty) |

### Roll out

To roll out to a limited audience, choose the toggle next to **Rollout to limited audience** and specify the users and groups to roll the connector out to. For more information, see [Staged rollout for Copilot connectors](/microsoft-365-copilot/connectors/staged-rollout).

Choose **Create** to deploy the connection. The Coda Enterprise connector starts indexing content immediately.

The following tables list the default values that are set.

#### Users

| Category | Description |
|----------|-------------|
| Access permissions | Only people with access to content in data source |
| Map identities | Data source identities mapped using Microsoft Entra IDs |

#### Content

| Category | Description |
|----------|-------------|
| Select time range | Last one year |
| Manage properties | 12 default properties and schema |

#### Sync

| Category | Description |
|----------|-------------|
| Incremental crawl | Every 15 minutes |
| Full crawl | Every day |

To customize these values, choose **Custom setup**. For more information, see [Customize settings](#customize-settings-optional).

After you create your connection, you can review the status in the **Connectors** section of the [Microsoft 365 admin center](https://admin.microsoft.com/).

## Customize settings (optional)

You can customize the default values for the Coda Enterprise connector settings. To edit settings, on the connector page in the admin center, choose **Custom setup**.

### Customize user settings

#### Access permissions

Choose one of the following access permissions:

- **Everyone**: Indexed data appears in search results for all users.
- **Only people with access to this data source** (default): Indexed data appears only for users who have access to it.

#### Mapping identities

Identity mapping is based on matching a Coda user's email ID to the user principal name (UPN) or email in Microsoft Entra ID. You can also define a custom mapping formula.

Choose **Microsoft Entra ID** if Coda user emails match the UPN or email in Microsoft Entra. If they don't match, choose **Non-Microsoft Entra ID**.

### Customize content settings

#### Content filter

To optimize performance, you can define a time range for indexing. The default time range is the last one year. Only content modified within the defined time range is indexed.

> [!CAUTION]
> If your Coda environment contains a large amount of content, choosing **All time** can affect platform performance.

#### Manage properties

You can view and modify the available Coda properties. You can assign schema attributes, semantic labels, and aliases. The following table lists the properties that are selected by default.

| Properties | Semantic label | Schema | Description |
|-----------|----------------|--------|-------------|
| authors | Authors | Query, Retrieve, Search | List of contributors (creator + editors) |
| browserLink | url | Retrieve | Web link to open the document in Coda |
| content | — | Search | Main content of the document |
| createdAt | CreatedDateTime | Query, Retrieve | Timestamp when the document was created |
| folderId | — | Query | Folder ID |
| folderName | ContainerName | Query, Retrieve, Search | Name of the container |
| folderURL | ContainerUrl | Query, Retrieve, Search | URL of the container |
| id | Identifier | Query, Retrieve | Unique identifier of the document |
| name | Title | Query, Retrieve, Search | Title of the document |
| owner | — | Query, Retrieve, Search | Owner of the document |
| ownerName | CreatedBy | Query, Retrieve, Search | User who created the document |
| updatedAt | LastModifiedDateTime | Query, Retrieve | Timestamp of the last modification |
| workspaceId | WorkspaceId | Query | Workspace identifier |
| workspaceName | — | Query, Retrieve, Search | Name of the workspace |

### Customize sync intervals

The refresh interval determines how often your data is synced between the data source and the Coda Enterprise connector index. You can configure the following sync intervals:

- **Full crawl** - Default value is every day. 
- **Incremental crawl** - Default value is every 15 minutes.

For more information, see [Guidelines for sync settings](/microsoft-365-copilot/connectors/deployment-overview#guidelines-for-sync-settings).
